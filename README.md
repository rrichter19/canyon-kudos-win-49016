## About Canyon Kudos

Canyon Kudos is a web tool designed to make employee recognition visible and organized. Teams can connect recognition activity with their core values, helping highlight contributions in a shared workplace setting.

The tool also supports presentation through a TV display and provides a structure for quarterly drawings. This makes it suitable for organizations that want recognition moments to be accessible to employees beyond the person who originally submitted them.

---

## Features

- Record and share employee recognition.
- Associate recognition with organizational core values.
- Present kudos on a TV display.
- Support quarterly recognition drawings.
- Provide a browser-based experience.
- Create a central place for recognition activity.
- Encourage recurring appreciation across the workplace.
